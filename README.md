# Mini Jam 1: Flappy Bird

Welcome to the first BU Game Development Club Mini-Jam! This is the starter code everyone will be given at the beginning of the meeting. 
You will need to download this and follow along with the presentation to implement the game.

## Installation Instructions

**Prerequisite**: Make sure you already have Godot 4.7 installed. If you don't, you can find a download link [here](https://godotengine.org).

1. Download this repository as a ZIP file (go to Code -> Download as ZIP)
2. Extract ZIP file wherever on your computer
3. Open Godot, click on Import, and navigate to your installation location
4. You're done!

### The Tasks

We will be implementing a few tasks together, and then you will have time to mess around and experiment.

1. Create a "Player" scene, and give it a sprite and a collider.
2. Make the Player move, fly, and collide with the ground.
3. Add in the already made "Pipes" scene to add pipes to our game.
4. Track when the player hits a pipe and kill the player.
5. Automatically spawn pipes in.

As with all mini-jams, don't forget to ask questions and have fun!!!
